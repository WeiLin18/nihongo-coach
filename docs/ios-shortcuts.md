# iOS 捷徑設定

iOS 上的 PWA 不能出現在分享選單，所以「從任何 App 送出」靠捷徑（Shortcuts）App 完成。
網址是 `https://nihongo-coach.<your-subdomain>.workers.dev`；`<APP_TOKEN>` 換成專案裡 `.prod.vars` 的 `APP_TOKEN`。

## 1.「查日文」——分享選單（文字或截圖都可以）

1. 捷徑 App →「＋」→ 命名「查日文」。
2. 點上方 ⓘ（詳細資訊）→ 開啟 **在分享表單中顯示**，接收類型只勾 **文字**、**影像**。
3. 加入動作（依序）：
   1. **如果**「捷徑輸入」**的類型是**「影像」
      - **從影像擷取文字**（輸入：捷徑輸入）
      - **設定變數** `內容` ＝ 擷取的文字
   2. **否則**
      - **設定變數** `內容` ＝ 捷徑輸入
   3. **結束如果**
   4. **取得 URL 內容**
      - URL：`https://nihongo-coach.<your-subdomain>.workers.dev/api/ask?format=text`
      - 方法：`POST`
      - 標頭：`Authorization` ＝ `Bearer <APP_TOKEN>`
      - 要求本文：`JSON`
        - `mode`（文字）＝ `lookup`
        - `text`（文字）＝ 變數 `內容`
        - `source`（文字）＝ `shortcut`
   5. **快速查看**（或 **顯示結果**）：取得 URL 內容 的結果
4. 使用方式：
   - Threads / IG / LINE / Slack：長按選取文字 →「分享…」→ 查日文
   - YouTube 字幕、IG 圖片：截圖 → 左下角縮圖 → 分享 → 查日文
   - 截圖裡有一長段文字時，捷徑會把整段送出，AI 會挑「最可能不懂的那個詞」解釋；想指定的話，改成選取文字送出。

## 2.「我想說」——動作按鈕 / Siri

1. 新增捷徑「我想說」。
2. 動作：
   1. **聽寫文字**（語言：中文（台灣））
   2. **取得 URL 內容**：同上，但 `mode` ＝ `zh2ja`，`text` ＝ 聽寫的文字
   3. **快速查看** 結果
3. iPhone 17：設定 → 動作按鈕 → 捷徑 → 選「我想說」。按住動作按鈕就能說中文、拿到日文。
4. 想要「幫我改」：複製這個捷徑，聽寫語言改日文、`mode` 改 `naturalize`。

## 提示
- 結果都會自動存成卡片，之後在 App 的「卡片」頁依分類複習。
- 第一次執行會問是否允許連到你的網域，選「永遠允許」。
- 結果頁只有文字；要聽示範發音、看重音高低線，請在 App 打開卡片。
